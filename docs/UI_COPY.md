# UI copy review

The recurring failure here was slogan filler: balanced, punchy phrases standing in for useful information. The surface may resemble a brand voice or a tutorial, but the player learns little. This is an editorial description, not a formal technical term or proof that a particular sentence was generated by an LLM.

The project should spend attention on controls, decisions, state, feedback, and concrete character/world details. Empty space needs no justification.

| Before | Change | Reason |
| --- | --- | --- |
| READ • BAIT • EMBRACE | Remove | Does not identify an action, timing cue, or event; repeats indefinitely |
| Land a hug. Read the reply. Run it back. | Remove | Restates the desired experience as a generic slogan |
| STEP INTO THE STREET | Play | Makes the button's result explicit |
| TAKE A BREATHER | Paused | Identifies the current state |
| WHIFF! CHECK RANGE AND HEIGHT | Out of reach / Facing away / Too high / Too low | Reports the failed contact condition |
| MUTUAL! TOO WHOLESOME TO CALL | Mutual hug (no point) | Explains why the score did not change |
| Learn the spacing, then own it | Steps forward before hugging | Describes a character's implemented move |
| HUG IN A MUG | Keep | Names a specific cafe in the world; the user likes it |

## Procedure for future work

1. Identify the player's question at this point. Examples: what button starts a match, why did that hug miss, which fighter do these keys control?
2. Decide whether text is needed. Animation, layout, feedback, or leaving space empty may be sufficient.
3. If text is needed, write the smallest accurate answer. Ground it in the implemented rule or current event.
4. Put optional instruction where the player can use it. Do not continually display vague strategy advice during a match.
5. Review all new strings together, outside the code. Remove repeated information, generic encouragement, unnecessary flavor captions, and descriptions interchangeable with another game's marketing.
6. Inspect the result in context. Brevity that hides a necessary rule is also a failure.

Punctuation, three-item lists, puns, and enthusiasm are not intrinsically bad. The test is whether the content earns the player's attention. Character-specific jokes, shop names, and a memorable reaction to a real event can belong; a slogan added because a panel has room does not.

## Useful instruction still missing

The menu contains literal controls and a brief rule summary. A proper interactive introduction should later let the player land a hug, miss at the edge of range, deflect a telegraphed attempt, bait an early deflect, and jump over a hug. Teach one action at a time with observable results. A rotating list of slogans is not a substitute for that work.
